# Generic tokens and notes

**Basics** is an addon built into the server, so it doesn't need the addon registry.
- **New games:** it's offered **ticked** under *Recommended add-ons* when you create a game. Untick it to leave it out.
- **Afterwards:** you can uninstall or update it like any other addon.

It adds two things.

## Generic token

A token that isn't tied to any card. It's useful for monsters, objects and markers that don't need a character sheet.

- **Place one:** right-click the map, then choose **Add → Generic token**. It appears where you clicked.
- **Edit it:** select the token and click the ⚙ next to it.
  - **Bar 1** and **Bar 2** each have a value and a maximum.
  - **Image → Choose…** picks the token's picture from the materials you can see.
- **Where its values live:** on the token itself. Each copy is independent.

### Who can place tokens

To place a token on a map, generic or from a card, a player needs **Control** on that map. Drawing and changing the map itself still need **Edit**.

To let everyone drop tokens on a map, right-click the map, open **Map Settings → Permissions**, and set **Everyone (default)** to **Control**.

## Notes

A **Note** is a rich-text card: headings, bold, italic, lists, checklists, quotes and links. It saves as you type.

It follows the game's look: with a theme switched on (*Game Settings → Appearance*), notes use the theme's colours, fonts and panel style.

- **Create one:** **Cards → Add Item**, choose the **Note** template, and give it a name.
- **Who sees it:** only its author and the GM. Other players don't see it.

## Letting players create cards from a template

Players can create cards from any template the GM has shared with them. The Note template is shared from the start.

- **To share a template:** give **Everyone** the **See** permission on it.
- **Who gets the new card:** a player's own card belongs to them, and the GM always has full rights to it. Use this for character sheets too.
- **What players can't create:** blank cards (without a template), templates, and cards from templates that weren't shared with them.
