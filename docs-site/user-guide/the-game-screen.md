# The game screen

When you open a game you see the **menu bar** at the top, the **windows** in the middle (the battle map, chat, cards and so on) and the **status bar** at the bottom. The GM decides which windows a new player starts with; everyone can rearrange their own screen afterwards.

## The menu bar

| Menu | What's in it |
|---|---|
| **Game** | **Run command**, **Show tutorial** and **Exit**. The GM also has **Get Invite URL**, which copies the link for new players (see [Inviting players](./getting-started-gm/inviting-players.md)). |
| **View** | Opens windows: **Tools**, **Chat**, **Dice**, **Players**, **Turn order**, **Cards** and **Materials**. The GM also has **Playlists**, **Soundboard**, **Manage Players** and the **Battle Maps** submenu. |
| **Settings** | **Player** (your name, colour, avatar, volumes) and **Keyboard Shortcuts**. The GM also has **Game**. See [Players and settings](./players-and-settings.md) and [Game settings](./game-settings.md). |
| **Layouts** | Saved window arrangements. See [Layouts](./layouts.md). |
| **Addons** | The GM's addon tools. See [Addons](./addons.md). |

Addons can add their own buttons and menus to the bar, and their own entries to these menus.

## Windows

Every window has a title tab. Several windows can share one place as tabs; click a tab to bring it to the front.

- **Move a window:** drag its tab. Dropped somewhere, it floats over the others.
- **Dock a window:** hold **Shift** while dragging its tab, then drop it on the edge of another window to split the space, or on its tabs to add it as a tab. The key can be changed, or switched off so windows always dock, in **Settings → Keyboard Shortcuts**.
- **Resize:** drag the line between two docked windows, or the edge of a floating one.
- **Close:** the **✕** on the tab closes that window; the **✕** at the right of the title bar closes the whole group.
- **Minimise:** a floating window has a minimise button. Minimised windows wait as chips in the status bar; click a chip to bring the window back.

The **…** button on a title bar has more:
- **Pop out to window** opens the window in a separate browser window, e.g. to put the chat on a second screen.
- **Lock position** stops the window from being dragged away by accident (a lock icon shows on the tab). **Unlock position** undoes it.
- **Hide header** hides the title bar to save space. A small **Show Header** button brings it back.

To get a window back after closing it, open it again from the **View** menu. To get back the arrangement the GM set up, use **Layouts → Reset my layout**.

## The status bar

- **Online** shows the connection to the GM's server. If it drops, the game reconnects by itself; see [Connection problems](./getting-started-player/connection-problems.md).
- **Minimised windows** appear in the middle.
- **Session ID** on the right identifies the game session. You may be asked for it when reporting a problem.

## The tutorial

The first time a player opens a game, a short tour points out the map, the tools, the chat and dice, cards, turn order, players and the menus. Steps for windows that aren't on screen are skipped. Replay it any time with **Game → Show tutorial**.

## Run command

**Game → Run command** (or **Shift+P**) opens a box for typing commands to the app itself, with suggestions and a description of each argument as you type. It's meant for addon makers and GMs who like the keyboard; you never need it to play.
