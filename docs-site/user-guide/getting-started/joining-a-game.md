# Joining a game

*For players.* You only need a browser: a recent Chrome, Edge, Firefox or Safari on a computer. Nothing to install.

## 1. Open the invite link

Your GM sends you a link like `https://nordvikmanager.pl/client/?game=…`. Open it.

## 2. Log in or register

The first time, you need a Nordvik Manager account.
- Choose **Register** and pick a **Username** and **Password**.
- **Email** is optional.
- If the form asks for an **Invite Code**, registration is invitation-only: ask your GM for a code. A registration link that already contains the code fills it in for you.

{/* SCREENSHOT: img/player-register.png — The player registration form. */}

Already have an account? Just log in. It's the same account for every game, whoever runs it.

## 3. Enter the password, if there is one

If the game is password-protected, you're asked for the password your GM gave you.

{/* SCREENSHOT: img/player-password.png — The "Password required" prompt. */}

## 4. You're in

The game opens once your browser has connected to the GM's computer, usually within a few seconds. What you see depends on what your GM has shared with you: maps, your character's card, your token.

{/* SCREENSHOT: img/player-first-view.png — A player's view right after joining. */}

## Next time

You don't need the link again. Open [nordvikmanager.pl/client](https://nordvikmanager.pl/client) and log in. Your lobby shows:
- **Your games:** every game you've joined. Choose **Join** on its card.
- **Join by ID:** paste a session ID your GM gave you.
- **Public Games:** games anyone may join, when the server allows them.

{/* SCREENSHOT: img/player-lobby.png — The player lobby: joined games, Join by ID and Public Games. */}

## If it doesn't connect

- **The game doesn't load:** your GM's server has to be running, with the game open. Check with your GM, then reload the page.
- **"You are banned from this server.":** the GM has banned your account from their server.
- **The connection keeps dropping, or never starts:**
  - Try another browser.
  - Try another network: some workplace and school networks block the direct connection games use.
