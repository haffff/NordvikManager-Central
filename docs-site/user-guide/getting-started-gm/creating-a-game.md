# Creating a game

A game holds everything for one campaign or one-shot: its maps, cards, resources, chat and players. You can have as many games as you like on one server.

## Create it

In the lobby, choose **Create new game**.

{/* SCREENSHOT: img/create-game-dialog.png — The "Create new game" dialog, filled in: cover image, title, Private selected, Basics ticked. */}

| Field | What it's for |
|---|---|
| **Cover image** | Shown on the game's card in your lobby and your players'. Optional. |
| **Title** | Required. |
| **Short summary** | A one-line teaser under the title. |
| **Public / Private** | **Public** lists the game under *Public Games* for every registered player, so anyone can join. **Private** keeps it invite-only: players need your [invite link](./inviting-players.md). Some central servers don't allow public games; then only Private is offered. |
| **Require a password to join** | Players must also enter this password. It works with both Public and Private. |
| **Description** | A longer text for players: what the game is, the schedule, house rules. |
| **Recommended add-ons** | Game-system add-ons to install right away. **Basics** (built-in, ticked by default) adds a generic token and a rich-text note. You can add or remove add-ons later. |

Choose **Create game**. The game appears in your lobby.

## The game card

{/* SCREENSHOT: img/game-card.png — A game card in the lobby, with the gear button, the lock badge (password) and Join. */}

- **Join** opens the game. This also **starts the session** that lets players connect.
- The **lock** badge means the game needs a password.
- The **gear** button opens the game's settings: rename it, change the description, copy the [invite link](./inviting-players.md), or delete the game.

:::danger[Deleting a game]
**Delete Game** (then **Confirm Delete**) removes the game and everything in it for good. Make a backup first if you might want it back: **Application Settings → Backups**.
:::

## Open the game

Choose **Join** on the card. The first time, the game is empty: add a map, cards and tokens before the players arrive.

{/* SCREENSHOT: img/empty-game.png — A freshly created game: the default panel layout with an empty battle map. */}

Players can connect **while the game's session is running**. It starts when you open the game and ends when you leave it for the lobby, or when the server stops. Then everyone is disconnected until you open the game again.

Closing the browser tab doesn't end the session; the server keeps it running. You can reopen the game and pick up where you were.
