# Game settings

:::note[GM only]
**Settings → Game** holds the settings of the whole game. Changes apply for everyone; some (like the layout settings) take effect for players the next time they load the game. Co-GMs (players with **Edit** on the game) have it too, but only the owner sees its **Permissions** tab; see [Permissions](./permissions.md#co-gms-edit-on-the-game).
:::

![Game Settings, General Settings tab](/img/user-guide/game-settings.png)

## General Settings

How the game appears in the game list: **Name of game**, **Color of game**, **Image of game**, **Summary of game** (the short text on the game card) and **Description of game** (the long one).

## Grid Settings

- **Custom Layers:** layers of your own above or below the built-in ones, and whether players see them. See [Layers](./battle-map/layers.md).
- **Use realistic distance system**, **Default distance per square** and **Default distance unit:** how distances are measured on maps that don't set their own (see [Map settings](./battle-map/map-settings.md)).

## Character Sheets

- **Add default Character sheet to player:** when a player joins the game for the first time, they get a card of their own from the template below, named after them. It opens for them the first time.
- **Character sheet template:** the template for that card, e.g. a game system's character sheet.

## Permissions

What players may do with the game itself. **Edit** on the game lets a player organise card and material folders, among other things. See [Permissions](./permissions.md).

## Properties

Extra values stored on the game, mostly for addons.

## Appearance

- **Stylesheets:** CSS files that restyle the game for every player, and themes from addons. See [Custom styling](./custom-styling.md).
- **Sounds & images:** replace the built-in **Empty image placeholder**, **Empty token image**, **Empty player avatar**, **Incoming chat message sound** and **Your turn sound** with your own: **Choose…** opens the game's materials (images or sounds, whichever fits); drop a file on the list to upload it.

## Advanced

- **Prevent players from saving their own layouts** and **Remember each player's layout between sessions:** see [Layouts](./layouts.md#game-settings-for-layouts).

## Outside the game

These are in the lobby (the game list) rather than in the game:
- **Renaming, the invite link, deleting the game:** the game card's gear button, see [Creating a game](./getting-started-gm/creating-a-game.md#the-game-card) and [Inviting players](./getting-started-gm/inviting-players.md).
- **Backups** of the whole server: see [Installing the server](./getting-started-gm/installing-the-server.md#back-up-your-games).
