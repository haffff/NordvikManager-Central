# User Guide

How to use Nordvik Manager, for Game Masters and Players.

New here?
- **Running a game:** start with [Getting started as a GM](./getting-started-gm/overview.md): install the server, create a game and invite your players.
- **Joining a game:** see [Getting started as a Player](./getting-started-player/joining-a-game.md). You only need a browser and the link your GM sent.

## Playing

- [The game screen](./the-game-screen.md): the menus, moving and docking windows, the tutorial.
- [Layouts](./layouts.md): saved window arrangements.
- [Battle map](./battle-map/overview.md): moving around, the tools, the right-click menu; [tokens](./battle-map/tokens.md), [map settings](./battle-map/map-settings.md) and [layers](./battle-map/layers.md).
- [Chat](./chat.md): messages, whispers and commands.
- [Rolling dice](./rolling-dice.md): the dice roller and roll formulas.
- [Turn order](./turn-order.md): the initiative tracker.
- [Cards](./cards.md): character sheets, notes and other cards.
- [Generic tokens and notes](./basics.md): the built-in Basics addon.
- [Materials](./materials.md): pictures, music and other files.
- [Players and your settings](./players-and-settings.md): the player list, your name and volume, keyboard shortcuts.

## Running a game (GM)

- [Music and sounds](./sound.md): playlists and the soundboard.
- [Permissions](./permissions.md): who may see and change what.
- [Game settings](./game-settings.md): everything in Settings → Game.
