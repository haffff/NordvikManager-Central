# Layouts

A **layout** is a saved arrangement of windows: which ones are open, where they're docked and how big they are. The **Layouts** menu holds the layouts you can use.

{/* SCREENSHOT: img/user-guide/layouts-menu.png — the Layouts menu open */}

## Using layouts

- **Switch layout:** pick one under **Layouts** in the menu. The windows rearrange at once.
- **Save your own:** **Layouts → Save current** and give it a name. It appears in the list for you.
- **Delete:** the **✕** next to a layout you saved.
- **Back to the start:** **Layouts → Reset my layout** returns to the game's default layout and forgets your remembered arrangement.

The battle map in a saved layout remembers which map it was showing.

## The game's layouts (GM)

:::note[GM only]
**Layouts → Layout Manager** manages every layout in the game.
:::

- **Default layout for new players:** the layout a player gets when they first open the game, and after **Reset my layout**. New games start with one called *Default*: the tools and battle map on the left, the chat on the right.
- **Save current arrangement as a new layout**, **Rename**, **Remove**.
- **Overwrite with current arrangement:** replaces a layout with what's on your screen now.
- **Apply this layout:** switches your own screen to it.
- **Share with all players:** lets players see and use the layout from their Layouts menu. A **shared** badge marks it. **Advanced / per-player permissions** shares it with chosen players only.
- **Force onto other players:** switches every connected player to this layout right away, e.g. to put everyone on the map for a fight. The layout must be shared first, or players couldn't load it.

{/* SCREENSHOT: img/user-guide/layout-manager.png — the Layout Manager with a default and a shared layout */}

## Game settings for layouts

In **Settings → Game → Advanced**:
- **Remember each player's layout between sessions:** each player's arrangement is saved in their browser and restored the next time they join. Without it, players start from the default layout every time.
- **Prevent players from saving their own layouts:** only the GM can create or overwrite layouts. Players can still use layouts shared with them.
