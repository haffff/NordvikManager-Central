# Addon Development Guide

This section documents how to build addons for Nordvik Manager: Cards, CardAPI, Actions, and the addon registry.

- [Cards](./cards/overview.md): sheets, notes and tools that live in the game. Build them as web pages,
  store their data as properties, and talk to the app through the [Card API](./cards/card-api.md).
- [Actions](./actions/overview.md): automate the game with steps, hooks, variables and scripts.
- [Packaging and release](./cards/packaging.md): turn the folder into an addon GMs can install, and publish
  it in the registry.
- [Developing with AI](./ai-guide.md): a guide file for AI coding assistants, so they follow the rules
  above.

To start a new addon, copy the [starter template](https://github.com/haffff/NordvikManager-Addons/tree/main/template).
